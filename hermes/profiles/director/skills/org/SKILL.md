# /org

Task for the organization: the text the user wrote after `/org`.

Follow your Director workflow: understand the goal, find the project directory, write the plan, create the workstream cards and the audit card, tell the user the plan and the card ids, then end your turn. Hermes wakes you when cards complete or block.

If you are not the `director` profile, do not run the workflow. Tell the user to open the Director bot and send `/org <task>` there.
