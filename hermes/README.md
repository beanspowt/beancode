# hermes

Source for the /org team as Hermes bots. Install it with `scripts\Install-BeanCodeHermes.ps1`;
the full description is in [docs/HERMES.md](../docs/HERMES.md).

| Path | Contents | Edit by hand |
|---|---|---|
| `roster.json` | One entry per bot: source OpenCode agents, model, reasoning level, description, toolsets | yes |
| `souls\<bot>.md` | Each bot's Hermes instructions | yes |
| `souls\_protocol.md` | Team protocol appended to every bot that works on Kanban cards | yes |
| `extra-skills\` | Skills that exist only for Hermes (`org`, the `/org` command) | yes |
| `profiles\<bot>\` | Generated Hermes profile distributions: `distribution.yaml`, `SOUL.md`, `config.yaml`, `skills\` | **no** |

`profiles\` is generated by `scripts\Build-BeanCodeHermes.ps1`. A bot's skills are not listed
anywhere in `hermes\`: they are the skill permissions of its source agents in
`config\opencode\agents\`, copied byte for byte from `config\opencode\skills\`. After changing
anything here or in `config\opencode`, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Build-BeanCodeHermes.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\Verify-BeanCodeHermes.ps1
```
